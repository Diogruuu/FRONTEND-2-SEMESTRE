# Atividade 02 — LUMA Festival

Landing page responsiva para um festival fictício de música independente. O projeto pratica classes utilitárias do Tailwind CSS em cores, tipografia, espaçamentos, dimensões, bordas, posicionamento, Flexbox, Grid e breakpoints.

## Como abrir

1. Abra `index.html` em um navegador com acesso à internet.
2. O Tailwind é carregado pelo Play CDN no próprio HTML; não é preciso instalar dependências ou compilar CSS.
3. Redimensione a janela para observar as mudanças responsivas.
